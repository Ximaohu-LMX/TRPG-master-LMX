**V3 正式开场的解析要求**

运行契约为 `collaboration_framework/contracts/module_v3.py` 中的 `ModuleContentV3`。
顶层 `opening_text` 保存当前默认起始路径、允许全房间朗读的完整原文。
`presentation.player_intro_pages` 仍用于车卡前展示，不能代替正式开场。

- 逐段复制公开朗读内容，保留顺序、对白、数量、时间和条件；仅规范化文档排版。
- 排除 KP 指导、隐藏真相、其它起始分支和私人 HO。将源文件、页码或从 0 开始的 DOCX 段落索引写入 provenance sidecar。
- 对照初始地点、人物和已知信息；开场已经交付的物品复用 `initial_custody`，桌上物品仍在原地点。模型只调整实际参与者的称呼和感知表达，不提交任何效果。
- 修改内容提升不可变模组版本，同步构建脚本、JSON、来源和内置发布声明。旧版本缺省仍可读取，序列化不新增 null 字段；已生成开场继续回放。

本次《幸福蛙蛙村》使用推荐导入 2 的庄园选项 A（51、53、55、57 段）；原文混用“100 美金”和“四百金币”，保留作者单位并作为内容审阅事项，运行时不转换货币。传单、照片和预付金信封有对应初始物品，管家有对应公开 NPC。
《银之锁》使用第 10、12 段；《追书人》使用 PDF 第 1 页“玩家信息”的两个段落。
《常暗之厢》的 sidecar 指向本机及仓库缺失的 PDF，暂保留旧版本兼容；不得用简介补作原文。
